# web

The local pixtro chat. A Next.js app; private, not published, and not deployable.

```bash
bun run dev        # from the repo root — builds the engine first
open http://localhost:3000        # an agent drives pixtro via your Claude Code login
```

`/` redirects to `/chat`. There is no hand-driven UI: the panel beside the conversation
draws whatever the agent last rendered — live, client-side, with `pixtro/core` — and carries
the storyboard editor and the PNG/GIF export.

The app spawns the local Claude Code CLI through the Agent SDK and answers requests to
localhost only, so it has nowhere to run but your own machine. See the "Chat" section of the
root `CLAUDE.md` for how it is put together.

`AGENTS.md` and `CLAUDE.md` in this directory are generated by `next dev`; commit them with
your work or they reappear as uncommitted changes.
